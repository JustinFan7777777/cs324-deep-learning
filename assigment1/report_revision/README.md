# Revised report and experiments

The complete instructions and final submission entry point are in
[the assignment-root README](../README.md).

This directory contains the editable TeX report source,
`assignment1_revised.ipynb`, reproducible experiment and verification scripts,
exact evidence under `results/`, and seven figures under `figures/`.

The generated report PDF and vector figures are local-only. The tracked PNG
figures allow PDF rebuilding from a fresh clone. Run all documented commands
from the assignment root. Packaging accepts `--output` for a new archive and
preserves existing ZIPs. The generated PDF is named `report.pdf` inside the
archive. LaTeX auxiliary files belong in `build/` and are excluded.
